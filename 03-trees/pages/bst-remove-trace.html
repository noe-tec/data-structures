          How to read the tree
          In remove(Node*& n, int x), n is a reference to a link: another name for
          root or for the left/right field of a parent. The thick blue link marked
          n is the one the running call can change; root (n) means n is root itself.
          Labels above a node, like n in findMin or old, are plain pointers.
          Blue fill: the node of the running call · blue ring: nodes of waiting calls.
          was 132: the value of that node was overwritten.
          Dashed blue: a node already unlinked, only reachable through a variable · red: deleted.

Tree in memory

        

        

          How to read the tree
          A node stores only info, left and right: its height is not stored anywhere.
          The h = … under a node is the value that height(n) returned for it;
          h = ? means that call has not returned yet.
          Blue fill: the node of the running call · blue ring: nodes of waiting calls.
          The label n shows where the variable of the running call points.
          A dashed nullptr box is an empty subtree: a call with n = nullptr, which returns −1.

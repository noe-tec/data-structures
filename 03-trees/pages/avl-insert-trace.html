Tree in memory

        

        

          How to read the tree
          Each node shows its stored h (height) and bf = height(right) − height(left).
          h … old: the stored height is out of date until update runs on that node.
          bf ? = not computed yet: bf is never stored in a node, and the program has not called bf
          on this node since the tree changed.
          Blue fill: the node of the running call · blue ring: nodes of waiting calls · red ring: bf = ±2.
          Labels like n or a show where the variables of the running call point.
          Dashed blue: nodes that, at that moment, are only reachable through a variable.

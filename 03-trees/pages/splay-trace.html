          How to read the tree
          Every key keeps its column, its place in sorted order, so a rotation shows as nodes moving up and down.
          Blue labels above a node, like x, p,
          g or a, b,
          are the pointer variables of the running call. Blue fill: the node of the running call.
          The thick blue link is the one the last line wrote.
          Every node also stores parent; it is drawn only while it does not match the child links yet:
          a red dashed arrow to the node it points to, or
          parent = nullptr.
          Dashed outline: a node that no path from root reaches, only a variable.
          Red: deleted. Inside a rotation the nodes keep their places until it returns.
